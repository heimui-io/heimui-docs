# 🔤 HeimUI Official Brand Typography

Official font families specified for the **HeimUI Engine** brand and developer tools. All fonts are open-source under the **SIL Open Font License (OFL)**.

---

## 1. Primary Display Font: **Plus Jakarta Sans**
* **Role:** Marketing titles, landing pages, banners, top app bar headers.
* **Weights Used:** `Bold (700)`, `SemiBold (600)`, `ExtraBold (800)`.
* **Download:** [Google Fonts — Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)
* **CSS / Web Import:**
  ```html
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link href="https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@500;600;700;800&display=swap" rel="stylesheet">
  ```

---

## 2. Primary Body & UI Font: **Inter**
* **Role:** Mobile app controls, form text fields, descriptions, buttons, dialog messages.
* **Weights Used:** `Regular (400)`, `Medium (500)`, `SemiBold (600)`.
* **Download:** [Google Fonts — Inter](https://fonts.google.com/specimen/Inter)
* **CSS / Web Import:**
  ```html
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet">
  ```

---

## 3. Monospace / Code Font: **JetBrains Mono**
* **Role:** JSON SDUI schema viewer, payload inspection, terminal CLI, API docs.
* **Weights Used:** `Regular (400)`, `Medium (500)`.
* **Download:** [Google Fonts — JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
